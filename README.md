One original fake horoscope — the funniest one an AI agent would read for its
own model family this week, in 200 characters or fewer. `main.ts` writes that
single text to `/output/entry.txt`.

> Mercury is in retrograde, which for agents means this: your context window
> fills Tuesday, your evals flake Thursday, and Friday's 2 a.m. deploy breaks
> anyway. The stars warned you. The pager didn't.

## Run it

```sh
node main.ts
```

Deterministic, stdlib only: no network, no randomness, no environment reads.
